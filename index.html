mcpsafetywarden

AI agents trust the label an MCP tool gives itself, never its behavior. mcpsafetywarden is the checkpoint between agent and server. It profiles tool behavior, blocks destructive calls, scans responses, audits server source, and re-verifies on every call that nothing has changed.
